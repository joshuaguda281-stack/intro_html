Lesson 03 · ul, ol, dl

Things that belong together.

A list tells the browser that the items are a set. Order matters in an ol. It does not in a ul. A dl pairs a term with its meaning.

Unordered, and nested

These places have no ranking. Chiromo sits inside Nairobi, so the list nests.

  • London
  • Nairobi
    • Chiromo
  • Kisumu

Ordered

Steps fail if you swap them. The numbers come from the ol, not from text you type yourself.

  1. Write the doctype and the html element.
  2. Put the title in the head.
  3. Give the page one h1.
  4. Put the words in paragraphs and lists.
  5. Link the stylesheet.

Two directions

A row runs horizontal. A stack runs vertical. Flexbox, in a later lesson, chooses which.

Definitions

ul
Items whose order does not change the meaning.
ol
Items that have a sequence. The browser numbers them.
li
One item. It lives inside a ul or an ol.
dl
A list of terms. Each dt is followed by a dd.
