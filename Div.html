Lesson 02 · div

Boxes, used on purpose.

A div groups things that belong in one box. It has no meaning of its own, which is why it is useful for layout and the wrong choice when a real element exists.

The box model

Every element is a box. From the outside in: margin, border, padding, content. The colors below are the four layers of one div.

margin
border
padding
content

Margin pushes other boxes away. Padding keeps the words off the border. Set them in CSS. The HTML only needs the element.

Choose the element that already has a name

A block with a heading is a section. A self-contained piece is an article. The bar at the top of this site is a header holding a nav. Reach for a div when you are only making a box, the way the diagram above is only a diagram.

This block is an article

It could be lifted out and still make sense. That is the test. A div would have grouped the same words, and a browser would have drawn them the same way. The article tag is the one that says why they are together.

<section>
  <h2>The box model</h2>
  <p>Every element is a box.</p>
</section>
